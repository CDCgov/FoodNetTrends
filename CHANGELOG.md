# CDCgov/FoodNetTrends: Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## v1.0 - 2025-05-18

Initial release of CDCgov/FoodNetTrends, created with the [nf-core](https://nf-co.re/) template.

### `Added`
- Bayesian hierarchical spline modeling for FoodNet surveillance data
- Support for multiple pathogens and data filtering options
- Interactive shell script for ease of use
- Comprehensive documentation and examples

### `Fixed`
- Initial release

### `Dependencies`
- Nextflow ≥ 24.10.4
- Singularity ≥ 4.1.4
- R packages (brms, dplyr, ggplot2, data.table, etc.)

### `Deprecated`
- None
